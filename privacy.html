Privacy Policy

Personal Assistant · Effective November 4, 2026

Personal Assistant ("the app") is a private tool used only by its developer, Daniel Tarkoff, on his own Google account. It is not available to the public.

Google data the app accesses

  • Google Calendar (read-only): event titles, times, locations and descriptions for the upcoming week.
  • Gmail (read-only): sender, subject, date, labels and the short snippet of recent inbox messages. Full message bodies and attachments are not read.
  • Gmail drafts (optional): if enabled by the owner, the app creates a single draft addressed to the owner containing the daily brief. It never sends email.

How the data is used

The data is used solely to generate the owner's daily brief and task list. To do this it is sent to Anthropic's API (Claude) for processing. The resulting brief is delivered only to the owner: in a browser window on the owner's computer, as a Gmail draft to the owner, and/or to a notification service configured by the owner.

Storage and retention

The app keeps a small state file on the owner's own computer or cloud storage containing message IDs, timestamps, the previous brief and tasks captured from email, so it can report only what is new. Entries are pruned automatically after roughly 30–60 days. No Google data is stored anywhere else by the app.

Sharing

Google user data is not sold, shared with third parties, used for advertising, or used to train models by the app. The only transfer is to Anthropic's API for processing, as described above.

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
